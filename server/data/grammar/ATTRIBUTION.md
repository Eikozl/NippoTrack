# Nihongo Mono grammar reference data

This directory vendors grammar material from [stndaru/nihongo-mono](https://github.com/stndaru/nihongo-mono), pinned to commit `ec0ba4a0ce1611c568b0e4f8a223eb8029249a25`.

The grammar content used here is licensed under MIT. Its full license text is preserved in `NIHONGO-MONO-MIT-LICENSE.txt`. Only the five grammar level catalog files and inventory metadata are included; no JMdict, KANJIDIC, or KanjiVG material is vendored here.
